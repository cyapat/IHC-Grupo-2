# WorkBridge

Landing page estatica para el proyecto de IHC y Programacion Web.

WorkBridge conecta jovenes de 18 a 25 anos de Lima Metropolitana con empleos de entrada, practicas y oportunidades part-time. Tambien ofrece a empresas un panel simple para publicar vacantes y revisar candidatos.

## Tecnologias

- HTML5
- CSS3
- Responsive Web Design
- Netlify

## Estructura

| Archivo | Descripcion |
| --- | --- |
| `index.html` | Landing page completa con hero, segmentos, pasos, features, categorias y CTA. |
| `wb_empresa_panel.html` | Panel empresa con panel general, lista postulantes, en proceso, contratados, vacantes y detalle de candidato integrado. |
| `style.css` | Design system compartido para todo el equipo. |
| `netlify.toml` | Configuracion basica de despliegue en Netlify. |

## Segmentos

- Jovenes postulantes.
- Empresas empleadoras.
